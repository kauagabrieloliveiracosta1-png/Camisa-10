# ⚽ Camisa 10 - Simulador de Carreira de Jogador

**Camisa 10** é um jogo simulador de carreira de futebol desenvolvido em HTML, CSS e JavaScript puro para navegadores de PC.

## 🚀 Como Executar Localmente
1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador (Chrome, Edge, Firefox).

## 🛠️ Como Hospedar no GitHub Pages
1. Crie um repositório no seu GitHub chamado `camisa10-game`.
2. Faça upload do arquivo `index.html` e `README.md`.
3. Vá em **Settings** > **Pages**.
4. Em **Branch**, selecione `main` (ou `master`) e salve.
5. Acesse seu jogo online gratuitamente!
